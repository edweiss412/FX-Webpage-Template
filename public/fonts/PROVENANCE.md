## Checksums

```
9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e  Inter-4.1.zip   (input, verified by the script)
fada467be8d8ebb5dccc346d29dc6ea37423da14c87dafed009631cb85632a54  InterVariable-latin.fada467b.woff2  (output, this machine)
```

**The output checksum is a record, not a contract.** `pyftsubset` output varies with fontTools version, brotli build, and host — so a regeneration elsewhere will differ in bytes while being entirely correct. Nothing in CI compares these bytes, deliberately: a byte-comparison gate would need a pinned Docker image and would fail on differences that do not matter (see the byte-comparison discipline in `AGENTS.md`).

What IS asserted, by `tests/styles/fontFeatureAvailability.test.ts`: every OpenType tag `app/globals.css` declares is present in whatever binary `app/fonts.css` points at, and both variation axes (`opsz`, `wght`) survive. That is a semantic contract on the thing that matters, and it holds across any correct regeneration.

## Why upstream rather than Google Fonts

Google Fonts serves a build of Inter with the character-variant and stylistic-set features stripped. Measured 2026-08-03 against the live latin subset: `calt ccmp dnom frac kern locl mark mkmk numr pnum tnum`, `wght` axis only. No `zero`, no `cv05`, no `cv08`, no `cv11`, no `ss01`–`ss08`, no `case`, no `opsz`.

That is why `"cv11" 1` sat in `app/globals.css` from `78662acb5` (2026-05-03) rendering nothing at all, on every route, until 2026-08-03.

## Why a subset rather than the verbatim release

The font is preloaded, so its weight lands on the first-visit critical path. Measured cold, median of 3, on `/auth/sign-in`:

| Throttling                     | verbatim 344 KB                     | remedy                          |
| ------------------------------ | ----------------------------------- | ------------------------------- |
| Slow 4G (1.6 Mbps / 150 ms)    | FCP 868 ms, font ready **3720 ms**  | FCP ~732 ms, font ready ~170 ms |
| Regular 3G (750 kbps / 300 ms) | FCP 1628 ms, font ready **8049 ms** | —                               |

`display: swap` prevents a blank-text flash but not the bandwidth contention (FCP +136–164 ms) or the late fallback→Inter reflow. `Cache-Control: immutable` makes this first-visit-only, which is precisely the visit `PRODUCT.md` cares about: crew opening a link on a personal phone on a venue floor.

Dropping Cyrillic, Greek and Vietnamese is the accepted cost. A name in those scripts falls back to the system font.

## Replacing or regenerating it

Run `scripts/subset-inter.sh`. It fetches the pinned release, verifies the input checksum, builds an isolated fontTools environment, and writes the subset. Then run the font tests — they are what tell you the regeneration is correct.

To move to a new upstream version, update `UPSTREAM_URL` and `UPSTREAM_SHA` in that script and the table above. To change coverage, edit the `LATIN` / `LATIN_EXT` ranges there — but that is a payload-vs-coverage decision of the kind recorded in the spec, not a maintenance step.
