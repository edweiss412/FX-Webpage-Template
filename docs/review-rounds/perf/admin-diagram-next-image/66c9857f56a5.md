**Judgment:** The rest is not mechanizable and should not be. Three findings were disproofs of an ARGUMENT the plan was making, not of a fact it stated: that the mandatory layout task could not have an honest red (one grep disproved it — the live anchor is `className="block"`); that the `sizes` oracle could observe a tier in a harness whose loader is width-independent; and that a two-tier fixture could exhibit a three-tier ladder's transitions. The lesson is in the escalation, not the arithmetic: rounds 1 and 2 corrected the NUMBER, round 3 found the INSTRUMENT could not read it. A stated derivation invites correction of its terms; only asking "what would observe this?" moves it. The plan now answers with the browser's own `img.currentSrc`, and the model it validates ships as exported code rather than as a paragraph.

**A plan sentence that PRE-COMMITS THE VERDICT on a future red.** Named separately from the judgment above because it is the most reusable thing this arc produced, and it is an authoring defect rather than a review one — no round caught it, execution did.

The plan told its own executor: a named regression check "must still hold byte-for-byte. If it moves, the encoder or the loader wiring is wrong, not the test." It moved. It was not the wiring: `next/image` writes an absolute `src`, so the path was byte-identical with the jsdom document origin prepended, and byte equality could not tell those apart. The sentence is wrong exactly when the assertion's own premise is imprecise, which is exactly when an executor most needs to look rather than to obey — and its effect is to convert a red into a foregone conclusion before anyone has seen it. The correct form states what the check is FOR (the path must not move) and stops there; what a failure MEANS is not knowable at authoring time.

Deliberately NOT proposed as a detector. A recognizer over plan prose for "if it moves, X is wrong" is the open-grammar shape the round-economy work already declines, and the corpus has the receipts. This belongs in `docs/agents/writing-plans.md` as a sentence about how regression checks are worded, if it recurs; one arc is not yet a pattern.
