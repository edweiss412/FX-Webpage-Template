# Round economy — fix/pill-size-draft-restored-note @ 53a1fc82fb36

## spec — 4 rounds

**Examined:** `docs/superpowers/specs/2026-08-30-pill-size-draft-restored-note-design.md`, a UI design for two ledger-filed phone P1s: an attention pill's type size at phone widths, and a transient note that a report draft was restored. Four rounds at this base, 21 findings, 20 confirmed and repaired, 1 refuted.

**Mechanizable:**

- **A spec that quotes its own measurements needs the probe to be re-run, not re-described.** Round 1's biggest finding was that the measurement table came from a probe that rebuilt the pill's markup by hand, and it was wrong by 18px on the one load the ledger row had independently measured. Nothing in the pipeline compared the two numbers; the ledger row said 84.4px and the spec said 66.39px, in the same repository, about the same element. A lint arm that flags a spec quoting a pixel figure for a surface whose ledger row already carries one would have caught it before dispatch. Filed as a documented limit rather than a row, per the process mint freeze.
- **`spec:lint` accepts a bare `` `:1234` `` citation as malformed but cannot see a citation that is well-formed and wrong.** 51 of round 1's 53 hard lint findings were one shape (missing path), fixed in one pass. The seven anchors that actually mattered were all well-formed and all pointed at the wrong line, and every one needed a human or a reviewer to open the file. The lint's `CITATION_SYMBOL_UNMATCHED` advisory is aimed at this and fired on four of the seven, but as an advisory among 20+ others it does not separate signal from noise.

**Judgment:**

- **The round-3 brief minted round 3.** It told the reviewer that "the highest-value thing you can do this round is attack the ACs as oracles." Seven findings came back, up from five, and six were AC-oracle findings. They were real and worth fixing, so this is not a complaint about the reviewer. It is the failure `AGENTS.md` already documents: a late-arc brief that names a fresh open axis gets that axis mined. The rule was in the corpus and the brief broke it anyway.
- **A stale brief manufactures a false finding, and it costs a full round to refute.** Round 3's F1 reported the measurement provenance as reconstructed. It was, in round 1. The brief carried round 1's description forward through two revisions after the measurement had been replaced, so the reviewer was reasoning from a document that contradicted the artifact. The existing rule is "verify every citation in a review brief before dispatch"; what it does not say, and should, is that a brief's *narrative* sections go stale exactly like its citations, and a revised brief needs the same sweep as a revised spec.
- **Two of five round-2 findings were assertions that could not fail in the case they named** (AC-4 evaluating the panel equation against a one-segment fixture while claiming to cover the tall-pill risk; AC-11 asserting `scrollTop` was unchanged when an in-flow node vanishing above the fold leaves `scrollTop` untouched *while* everything below moves). Both were written by me, in a spec whose own project rules carry an explicit anti-tautology section. Reading that section is not the same as applying it, and the gap between them is where these rounds went.

**Infra:**

- `tests/e2e/step3-review-modal.layout.spec.ts` matched no project regex in `playwright.config.ts` and ran nowhere. It was found while looking for coverage for one of the swept sites, not by any gate. Wiring it into the project made it discoverable locally; a later round found that CI names its specs explicitly, so the workflow needed the same edit. A spec that exists, passes, and is wired to nothing is invisible to every signal this repo has except someone going to look.
- The first local run of that spec was red on a missing `HASH_FOR_LOG_PEPPER` in the harness subprocess. A control run of the already-wired, CI-green sibling failed identically, which is what identified the red as a local environment gap rather than a property of the spec. Without the control run the honest reading would have been "the dead spec is dead for a reason", and the wiring would have been reverted.
