### The dominant cost, and it is not what the spec stage's was

The spec stage's cost was stating a class rule and not running it against the neighbouring instance.
The plan stage's is one level in: **repairs carrying the next round's defect.** Five of the eleven
were defects in this arc's own repairs — r2 F2 followed from r2 F1's partition, r3 F1 was r2 F2's
repair appended beside what it superseded, r4 F4 followed directly from r2 F2's decision to drop the
line from the record key, and r4 F2 from r3's baseline guard. A repair is a task and owes the class
sweep the original work owed; that rule was known and applied, and it still did not stop the chain,
because the sweep checked the class the finding named rather than what the repair newly enabled.

**The sharper form, from r4 F1, and the one worth carrying past this arc: a class sweep must check
each instance's failure DIRECTION, not only its syntax.** Three sites shared the identical
bare-identifier-callee shape. Two fail toward a silent FREE, so widening them is conservative. The
third feeds `hasPremise`, so widening it CREDITS a registration with a premise it does not have —
false certification, the direction the consequence bound names first. The sweep was correct about the
shape and wrong about the consequence, and it was justified in this plan's own words as "the same
one-line call". A repair whose safety argument is that it is syntactically identical to a safe one has
not made a safety argument.

### What would have cut the rounds

Two things, both cheap and both available before round 1.

1. **Run every task's red at its own commit boundary, rather than reasoning about it.** r1 F1 was
   exactly a boundary state that had been reasoned about; once the boundary probe existed
   (`docs/superpowers/specs/ci/probes/2026-08-21-premisescan-registrar-accept-sets/boundary.mts`), it
   settled r2 F1 as a measurement in one run and would have settled r1 F1 before dispatch.
2. **Ask, for every population a task measures, whether another task in the same plan writes into it.**
   That single question is r2 F2 in full, and nothing in the pre-draft verification pass asked it.
