**Judgment:** four calls, each recorded in the spec so a later reader does not re-derive them.

1. **The ledger row's own remedy was declined on measurement.** The row states a construct-aware

2. **Decline-and-surface was refused on a population count, not on cost.** The corpus holds six live

3. **The consequence bound was SCOPED rather than defended.** Round 2 found a bash-rejected input

   accepts, with a third population recording the rejected ones' movement in both directions.
4. **A widening that improves bash fidelity is still refused.** The `#`-comment rule makes the walk
   agree with bash where today it does not, and it is planted as a DEFECT in the probe's own
   self-test, because it is the parser growth the design fences. A fence that only rejects mistakes
   is easy; this one rejects an improvement.
