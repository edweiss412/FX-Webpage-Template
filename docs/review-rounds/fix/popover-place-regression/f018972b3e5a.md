## spec — 5 rounds

**Examined:** 5 counted rounds at this base, 5 across the arc (this is the only base — no rebase, no
mid-arc merge of `origin/main`). Findings declared: 3, 3, 3, 2, 0. APPROVE at round 5.

**Judgment:** Three of the four rounds were spent on one thing the first draft got wrong, and it was
worth every round. The arc opened as "three stale test expectations after a ratified layout change" —
a diagnosis that was correct about the CAUSE and wrong about the REPAIR. Round 1 found that the
rebuilt T-REGROW asserted containment, overflow, cap-absence and room-exceeds-body, and that all four
hold with a STALE placement, because `lib/popover/position.ts:135` derives the body's `y` from its
height and the resulting overhang goes INTO the trigger rather than out of the clip rect. The case
could not fail if `ShareHub`'s `bodyObserver` were deleted. That was not a regression this arc
introduced; the assertion had never existed. Rounds 2 and 3 then found the same shape twice more in
the repair itself: the cap-CLEAR branch (`removeProperty("max-height")`) that no case reached, and the
CANCEL direction where the box shrinks and a stale placement opens the gap instead of closing it.

The unifying defect is one habit, not three oversights: **asserting the state a transition lands in,
rather than the relationship the transition has to preserve.** Containment is a state. `GAP == 6` is a
relationship, and it is the one that discriminates. Every round after the first was the same lesson
applied to a direction the previous round had not walked — grow, clear, shrink — and, in round 4, resize. T-TRANSITION had been left asserting states after
three rounds of applying the lesson to T-REGROW, so a re-place that wrote the correct cap at the
wrong coordinate passed all of it; the planted case sat 173px off its trigger while contained and
uncapped.

**Mechanizable:** declined: the mechanizable part was mechanized in this PR rather than filed, and
the rest is not mechanizable. Detail follows, and the 2026-08-25 process mint freeze independently
bars a process-facing row for either half.
Both structural guards now register every settle site by control rather than counting one token, and
each new leg was verified by planting the two failures the guard exists to prevent (fold the assertion
into the retry; delete the retry). What is NOT mechanizable is the finding that started it: no
structural check can tell that an assertion set is satisfiable by a stale value. That took a reviewer
reading the placement arithmetic against the assertion list. The registry cannot express this surface
(Playwright), so planted-defect controls carry the discrimination load instead of a mutation score,
and each repair in the spec's §4 now names its own control.

**Infra:** One round-1 dispatch was rejected before reaching Codex — `--stage spec` requires
`--lint-doc`, and a second was rejected by `spec:lint` itself (8 malformed `:NNN` citations and a
missing "Resolved scope" heading). Neither produced a corpus row, both were wrapper-side, and both
were the gate working. Separately, a `grep --include=*.test.ts` with an unquoted glob returned nothing
and was read as "no gate exists"; the gate did exist, and CI found the missing
`docs/superpowers/specs/ci/README.md` row that a working command would have found locally. That is a
process lesson with a mechanical fix: quote the glob, and treat an empty search result as a reason to
check the command before concluding absence.

**Judgment:** The diff reviewer's findings were a near-subset of the spec reviewer's in every round,

### The shape of the count

Five rounds per stage, and the finding rate fell 3, 3, 3, 2, 0 on spec and 1, 2, 3, 0, 0 on diff. That
decay is the thing worth recording: rounds 1-4 each closed a distinct reachable branch with a
demonstrated control, and round 5 found nothing on either stage. This was not an arc that ratcheted a
recognizer — no round widened a grammar, and the product code was never touched. Every round's output
was an assertion that a planted defect could fail, and the planting was done and recorded each time
rather than argued.

The count is high because the FIRST repair was wrong in a way the red gate could not show: the suite
went green while the assertion set was satisfiable by a stale value. A green suite is not evidence
that the assertions discriminate, and this arc is the measured cost of learning that on a surface
where no mutation score is available to say so mechanically.
