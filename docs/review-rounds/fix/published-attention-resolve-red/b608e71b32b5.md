**Judgment:** seven of nine findings were two shapes, and both are prose defects rather than code defects.

*Stale claim* (rounds 1, 3): a comment or ledger sentence describing a state the same commit had just changed. Three instances: a FIXME comment above the case it had just been removed from, a workflow `paths:` comment saying six cases gate when seven now do, and the row's own "carried as test.fixme" framing. The trigger is uniform — this arc's whole job was changing which case runs, and every sentence anywhere that mentioned that fact became a candidate. Cheap to sweep, and the arc did sweep after round 1, which is why round 3's instance was in a file the round-1 sweep had not covered. The lesson is scope: sweep for the *fact that changed*, across every file type, not for the *file you edited*.

*Conclusion wider than its citation* (rounds 1, 2, 3): four instances, all mine, all the same move — evidence that supports a narrow reading, written up as a broad one. Calling a theory DISPROVED on a structural reading that could not bear it. Claiming a prop had "no opt-in call site anywhere" from a grep whose own `-v` filter had excluded the file that refutes it. Turning eight passing recorder signatures into a cause of one failure that was never instrumented. Attributing three loopback mechanisms to one client. Each was written while the underlying conclusion was correct, which is exactly what made them easy to write and hard to notice.

Two of the four were caught by the arc itself while sweeping for the others: a "16-run hunt" that was 8, and a "16 runs" that was 13. That is the sweep working, and it is also the tell — this arc produced numeric and scope claims faster than it verified them. The corrective that actually held was mechanical: every number in a filed row now traces to a quoted command and its output, and the row says which runs a number ranges over.

The one finding that was neither shape is round 2's other P1, and it is the arc's own anti-tautology failure. `expect.poll` resolves on its first match; `onResolved` fires before `router.refresh()`; so every pill assertion in the case was satisfiable by the optimistic paint, and a resolve that answered success and wrote nothing would have passed. Worth noting that the tautology was *inherited* — the comment claiming the pill "covers both phases without racing the refresh" predates this arc — and that rewriting the assertions without re-deriving that claim is how it survived. A claim in a comment you are editing around is not evidence.
