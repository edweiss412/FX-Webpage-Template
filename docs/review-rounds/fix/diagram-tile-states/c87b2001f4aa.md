The repair that closed it is not a sixth clause: **ask the engine.**
`checkVisibility({opacityProperty, visibilityProperty, contentVisibilityAuto})` is Chromium's own
answer and covers display, visibility, opacity and content-visibility in one call; colour alpha is
the single thing it does not model, so it is read separately. That pair is closed where the list was
open, and it carries a premise that the browser answers `checkVisibility` at all, so a browser
without it fails loudly instead of passing vacuously.

Generalisable, and stated as the lesson rather than the instance: **when successive rounds each add
one member to an accept-list of ways-to-be-wrong, the list is the defect.** Look for an authority
that already enumerates the domain — here the rendering engine — and delegate to it.
