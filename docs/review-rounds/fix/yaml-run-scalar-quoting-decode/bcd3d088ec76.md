`DECLARED.length - MATCHER_CANNOT_REACH.size`, `MATCHER_CANNOT_REACH.size` — so

Two candidates follow, and both are declined here with reasons.

declined: a check that every `path:NNN` citation in a spec or plan resolves to a
line that still exists. It catches the r4 SHAPE structurally, but not r4 itself —
that citation was in range and pointed at the wrong line, which no existence
check can see. Buying a guard that would have missed the very finding that
motivated it is the wrong trade, and saying so is cheaper than discovering it
after building. Written as a one-off sweep during r4 instead: 100 citations
across this arc's files, zero structurally broken.

and this arc's own `DECLARED` array had been using it from the start ("line
numbers are drafting-time locators"), which is the strongest evidence for it,
since that array is the one place the drift never happened. A ledger row would
