R1 (3, NEEDS-ATTENTION): the exemption guard pinned the control's class but not the enclosing element's, so `flex flex-col` on the parent blockified an exempt control silently; sites 5 and 8 located their control by `data-testid` alone, so a `<span>` keeping the testid and classes passed every geometry and colour assertion; the wiring guard recognised the oracle by its first two tokens, so `|| true` / `; exit 0` / a pipeline / `continue-on-error` all discarded the non-zero exit that is that step's entire output. R4: APPROVE, 0 findings — the round-3 repairs survive current-tree probes, and the convergence position the brief stated was not contested.

**Mechanizable:** "a sweep repaired the mechanism in hand rather than the class" — R1's three repairs each drew a sibling in R2, at a cost of one full round. The tell is available at authoring time and is cheap to check: when a guard pins a property (here, an element's `display`), enumerate the mechanisms that set THAT PROPERTY before writing the assertion, rather than the mechanism the finding named. JSX has exactly two for `display` on an element (`className`, `style`); a shell `run:` scalar has one closed character class for detaching exit status. Both are small, finite, and derivable in the minute before the first dispatch. The same shape cost this repo's classname-equivalence arc fourteen rounds. No new row: this is the existing class-sweep rule (AGENTS.md, "sweep to a derivation, not a longer list") applied one level deeper — to the mechanisms of a property, not just the instances of a defect.

**Judgment:** R3 finding 1 was the round where widening had to stop. className → inline style → component is a recogniser ratchet, and the next spellings (a component that sets `style`, one that renders a different tag) were already visible. The call was to make the guard FAIL CLOSED on an undecidable premise — the enclosing element must be a native tag, because that is the condition under which its class and style determine its display — and to write the decidability boundary into the file, with the residue (an ancestor further up, an external stylesheet, over a native parent) named as an accepted limit whose closing move is a real-browser computed-display assertion that spec §2 deliberately did not ratify for exempt sites. R4's brief stated that position as the convergence criterion before dispatch rather than after.
