## spec — 5 rounds

**The one shape worth carrying forward: a rule stated in prose and instantiated by hand.** It cost four of the five rounds, and each time the *reviewer* was right and my *repair* was the next round's defect.

- R2 found the battery could not distinguish a `(branch, stage)` exemption key from one keyed on `branch` alone. I repaired it by writing "one control per coordinate" as prose, then filling the cells myself.

Repaired with a DERIVED matrix: one row per `(key, coordinate)` over all four compound keys, nine cells, a missing control visible as an empty row.
- R3 also opened a second class (values asserted, never presences). I wrote that one as prose too, and listed the values by hand.
- R4 found two values the list omitted, plus a genuine P1 elsewhere. Repaired with a derived inventory: every value the change makes the code compute, each with its by-value assertion. Which I again assembled by hand.
- R5 found a tenth value the inventory omitted — `triggerRateByMonth[month].rate`, a third stored field rendered independently, so a hybrid publishes `213/282  57.8%` with each half individually passing its row. Repaired twice over: the inventory is now derived field-by-field from the `Report` type, and a rendered-line assertion was added that catches struct-versus-rendering disagreement whatever the field list omits.

The lesson is not "state the rule more carefully". It is that **a rule a human applies by hand is not a mechanism**, and the repair for an enumeration defect is a derivation, never a longer list. I needed telling three times, in the same document, having written the rule down myself each time. Both repairs now take that form, and the strongest of them is V11 — assert the rendered line verbatim — because it is the one that stays correct when the enumeration behind it is wrong.

R4's P1 was outside that pattern and is the finding I am most glad of: §3.1 said a clause-B obligation is discharged by a section in "any `.md`" under the directory, but `readArcs` recognizes only `^[0-9a-f]{12}\.md$` and the corpus deliberately ignores stray prose files.
