**Mechanizable:** the "RED derives from a test-local fixture" shape.
`spec:lint --exec-red` runs `red-state=live` commands and probes collection for
vitest-shaped targets, but nothing checks whether an `authored` marker's
`red-target` is on the import path the test's failure actually takes; nine
findings here were exactly that. The mechanical form is narrow: for an
`authored` marker whose test file imports a module that is untracked, the
target must be that module's path (the legal form), and for a tracked target
the test's import graph must resolve without the target. Filed against the
existing `LIM-AUTHORED-RED` class: `BL-SPECLINT-RED-TRUTH-PROBE` already owns
the truth half of `red=` validity (BACKLOG.md, filed 2026-08-27), and this
arc's nine instances are evidence for that row, not a new one.
