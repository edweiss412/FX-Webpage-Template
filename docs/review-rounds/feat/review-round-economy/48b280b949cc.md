Four mechanizable rules come out of it, all cheap and all applied here:

1. **A recognizer bounded by a NUMBER will be found by the next reviewer.** The emphasis matcher's cap went one delimiter, two, three; round 2 removed the cap and round 4 still found a shape, because the next cap was positional. Round 5 found one more, because the positional fix was anchored by a backreference — an *identity* constraint where CommonMark's is a *mirror*. Each repair that named a shape got found; the one that finally held derives the closer from the opener, so nesting depth and composition are handled rather than listed.
2. **A key that can ALIAS is not a clock.** Count recency cost three rounds keyed on the wrong thing (the attempt, then the session) before landing on a monotonic per-attempt ordinal.
3. **A per-site sweep of a value-domain defect does not converge; a derived one does.** The unsafe-integer defect recurred in rounds 3, 4 and 5 — five call sites, three review rounds, each repair fixing the site it was shown. It stopped when the test stopped naming sites: the row-schema test now derives its field list from the fixture, so a numeric field added later is covered by default. That is the same fail-by-default posture the corpus walk already uses, and it is what the class-sweep rule in `AGENTS.md` should mean in practice — sweep to a *derivation*, not to a longer list.

4. **When four rounds land on one function, the mechanism is wrong — stop repairing it and ask what question it needs to answer.** Rounds 2, 4, 5 and 6 were all one hand-rolled markdown unwrapper, and each repair was sound and still incomplete: a cap of three, then label-vs-line placement, then mirrored-vs-identical closers, then a greedy closer ambiguous with the value's opener. Round 6's fix (consume exactly `mirror(opener)`) was correct and would have invited a seventh.

   The parser was then **deleted instead of fixed**. Every value in `KNOWN_OUTCOMES` is letters and one hyphen, so no emphasis character can appear in a valid outcome — which means emphasis STRUCTURE is irrelevant to identifying one, and the right move is to delete every `*`, `_` and backtick and read the plain line underneath. Lossless for any valid outcome, incapable of making an invalid one valid, and it makes all four rounds' findings structurally unreachable rather than individually patched. **Net −71 lines, all 307 wrapper tests still green**, including every shape those four rounds contributed.

   The tell was available from round 4 onward and was read as "another instance of a class" when it was really "this function is answering the wrong question". A recognizer that keeps losing to one more shape is usually parsing something it does not need to parse.

   **Round 7 is the honest coda, and it cost a round because the simplification was over-claimed.** "Lossless for any valid outcome and incapable of making an invalid one valid" was written into the code, the commit and the review brief — and the second half was simply false. `VERDICT: AP_PROVE` is not APPROVE and became APPROVE, with exit 0 and a counted corpus row. Deleting the parser was right; asserting a property of it without probing that property was not, and a claim stated in three places is not evidence in any of them. The repair restricts deletion to runs not flanked by word characters on both sides — CommonMark's own rule for intraword `_` — chosen on DIRECTION: a lost verdict is loud (exit 3, an operator reading a result), a fabricated one is silent and lands in the corpus as fact. Emphasis inside the word is now a documented limit in the surfaced direction.

That third rule is the sharpest thing this arc measured, because it is the class-sweep rule in `AGENTS.md` failing three times running on the arc that cites it. Finding the class is not the hard part; the hard part is that a sweep verified by enumeration re-opens the moment someone adds a site.

The fourth is the one that would have saved the most rounds, and it subsumes a lesser lesson worth keeping: every fixture through round 5 happened to put a space after the colon, so five rounds of tests never exercised the one place the tokenization was ambiguous. A fixture family sharing an accidental property is itself a coverage gap — the anti-tautology rule read as covering fixture *shape*, not only assertion scope. But the deeper point is that round 6 should not have needed a fixture at all: by then the surface had signalled twice over that it was parsing structure it did not need.

`BL-CODEX-GUARD-COMMONMARK-PARSE` was filed at round 4 to replace this recognizer with a real mdast parse, and it is now **narrower than when it was filed** — the verdict/count marker no longer needs a markdown parser at all. What remains under that entry is `stripCodeBlocks`, which genuinely does need block structure.

**Judgment:** Whether to keep repairing at all past round 2. Each round's findings were genuinely in the losing direction — a lost verdict files a completed review as an infrastructure fault, and a restated count puts a number in the corpus the reviewer never wrote — so the consequence bound admitted every one, and none was a "the guard does not pin what it claims" ratchet. Continuing was right, but only because the bound held; the moment findings turned into "here is one more shape that leaks", `BL-CODEX-GUARD-COMMONMARK-PARSE` was already filed to take them.

The honest counter-reading, recorded because it is the one a later reader should weigh: five rounds on two recognizers is a lot, and each round's repair was *sound* yet incomplete in the same direction — toward the shape it was shown. A reviewer that can keep producing one more shape is a signal the REPAIR is the wrong kind, not that the reviewer should stop. Rounds 2 and 4 should have reached for the derived form immediately rather than a wider pattern.

Also judgment: a mutation probe, not the reviewer, found the round-3 repair's own gap (writer 4 never placed its attempt on the clock), and another found round 4's row-schema check to be unpinned defensive code. Probing each repair with the mutant that should kill it caught two defects five review rounds had not, at a fraction of a round's cost. Worth doing before the dispatch, not after.
