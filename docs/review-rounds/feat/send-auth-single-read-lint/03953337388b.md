**Round 4 then found six MORE instances of the same class, and that is the honest result of this
filing.** The cover was incomplete in a way worth naming precisely: it enumerated weaker
implementations of each RULE, but not of the ANALYSIS PRIMITIVES the rules are built from — which AST
node kinds are inspected, which comment syntaxes are recognized, which import forms are followed, how
far an exemption reaches. A rule can be stated exactly and still be satisfied by a scanner that reads
only part of the language: inspecting `MethodSignature` but not `PropertySignature`; exempting every
ambient reference rather than only a callback handoff; recognizing the two nesting kinds the fixtures
happened to use; skipping a derivation's entire initializer subtree instead of exempting only the reads
taken through it; comparing an import's local name rather than following the symbol; and recognizing
comments in TypeScript while AC-5 mandates a JSX impostor the corpus could not contain, because the
fixture set was constrained to a non-JSX extension.

The round is nonetheless the cover working as intended rather than failing: the brief declared an
instance of this class EXPECTED ABSENT and said that finding one anyway meant the cover was incomplete,
and the reviewer returned all six at once instead of one per round. Six instances in a single round,
against three rounds to surface the first three, is the difference the derived cover made.

**Mechanizable:** none, and deliberately so. The check the class yields —
*name the strictly weaker implementation, confirm a fixture kills it* — is a review and authoring
discipline, not a predicate. Mechanizing it would require deciding whether an arbitrary weaker program
passes an arbitrary fixture set, which is the specification problem itself. It is adopted as batch
guidance instead, stated as distinct from the anti-tautology rule and applying alongside it: **anti-
tautology asks whether an assertion can fail at all; this asks whether it can fail for the RIGHT
REASON.** A fixture set that a weaker implementation passes is green about a property it never tested.

**Infra:** three, all measured on this arc.

  function emits for an underivable probe. Since `AGENTS.md` mandates the wrapper for every heavy
  phase, the arm cannot see exactly the class the repo requires be wrapped. Filed as a peer row; both
  homes are the plan's closeout and the sibling filing under `4b5028b446a4`.
