**Mechanizable — three of the eight, and two of those already had a machine.**

- **The test-validity pair (R2) is the class the anti-tautology rule names, and it is not mechanizable
  in general — but its instances were.** The exit-window case reused a helper that had already
  demoted the slide, so its error landed in the placeholder branch and the gate under test was never
  asked anything; deleting the gate would have left the case green. The repair is a mutation probe,
  which is mechanical and cheap: `closedAtNonce !== openNonce` replaced with `true` now reds the case
  (1 failed / 40 passed). Any guard whose claim is "this condition suppresses something" can be
  settled that way in about a minute, and this arc did not do it until a reviewer asked twice.
- **The repeat (R3 F1) was an edit that reported success and wrote nothing.** The Python edit script
  aborted on a later assertion after building the new text, so the file was never written while the
  commit message said it was fixed. Mechanizable outright: an edit script that asserts anchors should
  write incrementally or verify the write, and the cheap habit is to re-grep the anchor after the
  edit rather than trust the exit status of the tool that made it.
- **The count claims (R4 F2) are derivable.** "15 tests" was written by hand and was wrong by one;
  the true numbers come from `vitest -t "<describe>"`, which prints them. A filing or closeout that
  states a count should state the command that produced it, which this one now does.

**Judgment — the prose findings were not noise, and the pattern in them is the lesson.** Three
successive rounds each found the retired mechanism (`closingRef`, then `lastNonce`, then both again)
surviving in a different file: the spec's Set clause, then its clear-condition 3, then the plan's
GREEN line, the HANDOFF's binding-shapes line, and the closeout's tables. Each round I repaired the
sites the reviewer named. That is the drip-feed the class-sweep rule exists to prevent, and the
correct move was available from R1: `rg` the retired names across the arc's own documents and repair
every hit in one commit, then verify by grep that the only survivors are explicitly historical. The
final sweep did exactly that and took a few minutes.

**Infra:** the reviewer's sandbox could not start Vitest in any round (denied temporary-directory

be re-established as HEAD after every repair, and each reorder rewrites the SHAs the previous round's
findings cited.
