## diff — 5 rounds

**Examined:** all five rounds (r1 BLOCKING/1, r2 BLOCKING/1, r3 BLOCKING/2, r4 NEEDS-ATTENTION/1, r5 APPROVE/0) on the whole diff — the bump, the forced build-config repair, the guard it teaches, and the outcome-A ledger archive.

**Mechanizable:** two shapes, one of them squarely so. (1) **`extends`-array replacement semantics** (r1, the only finding that touched shipped behavior): a new tsconfig declaring `exclude` alongside `extends` silently drops every inherited exclusion, and that is decidable from the two files alone — `tsc --showConfig` on both projects and a set-difference over their resolved file lists answers it in one command, with no judgment. The repair shipped exactly that check as a derivation in the r30 guard block, so the class is now closed in-repo rather than in a reviewer's head; a general `spec:lint`-style rule ("a config with `extends` that redeclares an array key must be diffed against the parent's resolved set") would have killed the round before dispatch. (2) **Stale cardinality after a list grows** (r4): "three future shapes" over a four-item list is a numeric-noun mismatch of the kind `NUMERIC_NOUN_MISMATCH` already recognizes; extending it to count the sibling list items directly beneath the claim would have caught it mechanically.

**Judgment:** the sensor-visibility findings (r2, r3-1) were the review earning its keep, and neither is reachable by a checker. The claim under audit was not "this code is wrong" but "this SHIPPED DOC asserts a monitoring property the CI configuration does not provide" — the reviewer had to compose three independent facts (the workflow's `if: failure() || workflow_dispatch` upload gate, `trace: "on-first-retry"` under `retries: 2`, and the measured absence of the marker from run logs) into the shape of a future event nobody had run. That is exactly the reasoning that separates an archived entry with an honest limits record from one whose un-archive trigger quietly never fires. r3-2 (two sites the r2 sweep missed) is the class-sweep discipline catching an incomplete sweep, which is the intended failure mode of that rule rather than a new one.

**Infra:** none. Five dispatches, five verdicts on attempt 1, no wrapper faults and no silent deaths — the same clean record the spec and plan stages had, so this arc contributes no evidence about the reaper class.
