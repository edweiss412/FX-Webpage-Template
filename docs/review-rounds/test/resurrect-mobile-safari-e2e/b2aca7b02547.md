**Mechanizable:** most rounds were spent on classes a check could have closed before
dispatch, and each is worth wiring rather than remembering.

- **The retried-interaction shape** (R3 P1 `tapToggle`, R4 P1 `clickSection`). Both
  wrapped a user interaction in `toPass`, which makes "the first tap was dropped"
  indistinguishable from "hydration was slow" — the suite then passes on a product that
  needs two taps. I repaired the first instance and shipped the second one file away, so
  the miss was not knowing the rule but not sweeping it. Grep-able:
  a `.click()` inside a `toPass`/retry wrapper in `tests/e2e/**`. The repaired form is
  the pattern to enforce — gate readiness on React's `__reactProps$…` hydration marker,
  then interact exactly once.
- **Whole-response Supabase holds** (R1 F3, R2 F1). `const x = await admin…` instead of
  `{ data, error }`. Invariant 9 already states it; what was missing was running the
  derivation (`rg -nE 'const \w+ = await admin'` over the touched specs) rather than
  fixing the sites I happened to look at. R2 existed only because R1's repair stopped at
  two of three sites in one function.

**Stale-topology prose** (R4 F3, R5, R6 F2 — the dominant tail). Comments and docs that
described the world before the diff: "four under desktop-chromium" when six resolve,
crew-page's "the desktop-chromium project early-returns from every test" after those
gates were deleted, `bodyChildCount` after the ratified field became `paintedTextLength`,
right-now-transitions named as a live writer after it was skipped. Two more were
introduced BY the repairs — a citation to `tests/visibility/openingReelText.ts` (the file
is `.test.ts`) and a DEFERRED row labelled "STILL OPEN" that then said it was moot. The
derivation exists and I should have run it every round rather than at the end: for each
touched surface, re-grep the identifiers the diff changed (project names, field names,
route shapes, spec basenames) across comments, not only code. `spec-citation-integrity`
already covers the `file:line` half; nothing covers the prose half.

**Judgment:** two rounds were genuine design calls that no checker would have made.

- **R1 F1 / R2 F2 — where a deviation gets ratified.** The shipped no-FOUC oracle and the
  fired valve were both defensible, and both were recorded only in commit messages. The
  correct home is the canonical spec (invariant 7); the reviewer was right that a
  commit-message rationale is not ratification.
- **R4 F2 — inv4 credited a crossfade it never performed.** 190 seconds of clock advance
  against a comment claiming a day boundary. Fixing it falsified the block's other
  assertion (`|after-before| <= 0.5px` is false across a real state change: 183.890625 vs
  176), which is the more valuable finding — an equality claim that had never executed.
- **R6 F1 — attribute assertions are not accessibility assertions.** The a11y case checked
  `aria-pressed`/`aria-label` on a testid, which `aria-hidden="true"` or a `<div>` swap
  satisfies while removing the named button from the tree entirely. Now resolved by role
  AND computed accessible name; the `aria-hidden` mutant fails to resolve the locator.

**Infra:** two rounds were slowed by environment rather than by the diff.

- Real CI rejected round 1's wiring for a reason no local run could reproduce: the
  runner is UTC, and two fixture times coincided with locally-rendered clock values
  (`8:00am` == noon-UTC in `America/New_York`). Every local verification after that ran
  under `TZ=UTC`, which is the cheap fix and should be the default for any suite pinning
  a clock.
- `TEST_DATABASE_URL` in `.env.local` points at the shared validation project and is
  captured at module load by `lockedCrewRestriction.ts`, so a multi-spec local run sends
  fixture writes to the wrong database and reports "update matched no crew row" while the
  row is present locally. Filed as `BL-LOCKED-FIXTURE-HELPER-TARGETS-REMOTE-DB`.
- `font-rendering-census.spec.ts:259` fails crew-e2e intermittently on unrelated branches
  too, which makes any "N consecutive green runs" bar a coin flip. Filed as
  `BL-FONT-CENSUS-ORACLE-FLAKE-BLOCKS-CREW-E2E`.
