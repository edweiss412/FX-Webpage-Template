an open enumeration: the survivor set **mixes genuine drift candidates with benign

what a tripwire costs. So this pass does not adjudicate per-row truth. It answers the one
question §1.2 makes a defect gate:

### The defect this pass found, and repaired

The first run of the shipped arm emitted **212** rows, four of which were wrong structure
class. A grouping comma is a word boundary, so the recognizer read the FIRST DIGIT GROUP of
a comma-grouped number as the whole cardinal:

| row | text | read as |
| --- | --- | --- |
| `docs/superpowers/specs/ci/2026-07-06-mutation-harness-sharding.md:77` | `every 5,000 parsed mutants` | `every 5` |
| `docs/superpowers/specs/ci/2026-07-06-mutation-harness-sharding.md:78` | `at each 5,000-mutant yield` | `each 5` |
| `docs/superpowers/specs/parser/2026-08-07-parser-mutation-wave-design.md:319` | `all 5,022 eligible data rows` | `all 5` |
| `docs/superpowers/specs/parser/2026-08-07-parser-mutation-wave-design.md:345` | `all 7,842 siteIds` | `all 7` |

Two of the four are precisely the four-digit populations the three-digit width bound exists
to exclude, so the bound was being defeated by the separator rather than applied; the other
two are frequencies, the class the time-unit gate exists to exclude. Repaired by NARROWING —
a cardinal followed by a grouping comma or a decimal point is a fragment of a longer literal
and the arm declines to classify it — and swept by shape, so the decimal form is declined
with it though it does not occur in the corpus today. Post-repair population: **208**.

### Class definitions

- **wrong structure class** — the matched text is not a universal-quantifier claim over a
  population. A defect by §1.2, settled by probe. Now zero.
- **historical-record residue** — the clause's subject is a COMPLETED RUN (a probe, audit,
  sweep, survey, replay, measurement) or an explicitly SUPERSEDED state (an earlier draft, a
  pre-arc baseline). The claim is about a finished observation, so nothing can drift away
  from it. These are genuine accept-set members; the advisory is correct and uninteresting.
- **live-enumerated claim** — everything else: a live universal over a population the
  document enumerates elsewhere, with no probe beside the claim. This is the tripwire's
  intended target, and per §1.2 it deliberately mixes benign restatements with genuine drift
  candidates. E1 — the escape that motivated the arm — is this class.

### Method, stated so the pass is auditable

Each row's class was decided from the CLAUSE the quantifier sits in (from the preceding
clause break to the following one), by the criteria above. The first pass over-assigned
`historical-record` by keying on words like "already" and "verified", which appear in claims
about LIVE code — exactly what can drift. The rule was tightened to require a completed-run
subject, and fourteen rows were moved by hand and are named in the classifier so the
corrections are visible rather than asserted. Rows moved to `live-enumerated`: twelve, each a
live-code or live-test-requirement claim wearing a past-tense verb. Rows moved to
`historical-record`: two, each a continuation sentence of a probe result whose own clause
did not name the run.

## What this informs

**Advisory copy.** The message names the cardinal, quotes the claim line, and quotes one
other-section line carrying the same cardinal. The `live-enumerated` majority confirms the
quoted evidence line is the useful part: a reader resolves most of these in one glance by
comparing the two lines, without opening the document.

**Documented limits (spec §7).** Two new limits, both found here:

1. **A cardinal inside an arithmetic expression is read as its first factor.**
   `all 9 × 10 = 90 possible pairs` (`docs/superpowers/specs/v1-pre-deployment-amendments/2026-05-19-solo-dev-ux-validation-design.md:472`)
   and `all 3×2/2 = 3 pairs` (`docs/superpowers/specs/2026-07-20-show-scoped-alert-copy-design.md:299`) emit with the
   cardinal `9` and `3`. This is NOT the wrong-structure-class defect above: both lines are
   genuine universal claims over enumerated populations, so the advisory fires correctly and
   the message quotes the whole line, which is what the reader acts on. The only consequence
   is a less precise cardinal in the message, and in the enumeration gate a wrong key can
   only produce SILENCE where an emission was due — the conservative direction. Parsing
   arithmetic to fix it is the recognizer growth spec §1.1 rules out.
2. **One advisory per line.** The arm takes the FIRST accept-set match on a line, matching
   the instrument, so a second universal+cardinal claim on the same line is not separately
   reported. The line is quoted in full, so the reader sees both.
